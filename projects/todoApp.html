My First Actual Project

Todo List Application

Like many basic programmers the "Todo List" application is a necessity to learn. This project was done in C and can be found in my GitHub Repo.

How it started

Foreward

First and foremost about me, I do not like having to just blindly follow tutorials. I hear about this place called Tutorial Hell. The thing I like about this CS Adventure is the ability to craft and create. I believe if your hand is held too tight, it doesn't allow you the ability to process things yourself for the future.

Project Background

This project was programed using C. I had spent the Summer of 2026 completing the CS50 course provided by Harvard University through edx.com. The course began with the student using Scratch, but then transitioned into using C.

I had heard through the grapevine of the internet that C was a complex language. I had some familiarity prior with Python specifically regarding to using it to solve answers in my Probability and Statistics course I had completed some years ago. But C... C looks nothing like Python, although I was determined to learn it.

This project is my first sudo-finished project. Although there is still much that can be done for this project, I am happy to leave it here in the meantime as it has served its purpose in teaching me several C and CS topics.

I was using VIM / NeoVIM and was interested in attempting to create my own. I had almost no knowledge that this was far from a good idea as a first project. I had no idea it required knowledge on how to manipulate terminal settings. But I attempted to learn it and found that it was futile. I noticed I was just blindly following a tutorial and making notes in my code.

As stated previously, I do not like to do that. So I went into at a much more basic form. I researched how to read and write data in C. That followed into building a typewritter-like functionality that would write to a file, line-by-line.

Project Function

Starting from the functionality of a typewriter, I found one by one things I could manipulate about it. I began with a line counter, already it looked like a todo list. One could write:

		
		1. Clean bedroom
		2. Wash counters
		3. Get groceries

This basic functionality introduced me to structs, I created a struct for tasks starting with their id and the description. I then created menus to allow the user to create a new tasklist, append a current tasklist, and view a tasklist.
